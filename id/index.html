Kebijakan Privasi — Moje Szczepienia

Terakhir diperbarui: 2026-05-06 · Tanggal berlaku: 2026-05-06

1. Siapa kami

Moje Szczepienia adalah pengatur vaksinasi seluler untuk keluarga: kalender, riwayat, dan pengingat untuk vaksinasi anggota keluarga. Aplikasi ini hanya bersifat informasional dan organisasional — tidak mendiagnosis, mengobati, mencegah penyakit, maupun menggantikan konsultasi medis. Semua entri vaksinasi disimpan secara lokal di perangkat Anda dalam penyimpanan terenkripsi; tidak ada data medis yang dikirim ke server kami.

Pengontrol data: Maciej Siemiński — pengembang Moje Szczepienia. Kontak: mail@macsiem.dev

Untuk versi aplikasi yang didistribusikan melalui Google Play, pengendali data adalah LICENCEPRO POLSKA Sp. z o.o., ul. Huculska 6, 00-730 Warszawa, Polska.

Kebijakan Privasi ini menjelaskan data pribadi apa yang diproses Moje Szczepienia, bagaimana, mengapa, dan hak-hak apa yang Anda miliki.

2. Ringkasan singkat

Moje Szczepienia adalah pengatur vaksinasi pribadi — catatan vaksinasi tetap ada di perangkat Anda dalam penyimpanan lokal terenkripsi. Kami tidak menjalankan server yang menyimpan data medis Anda. Kami menggunakan Google AdMob (hanya di layar Pengaturan, tidak pernah di layar data kesehatan), Sentry untuk pelaporan kerusakan, sinkronisasi opsional ke iCloud / Google Drive Anda sendiri, dan penagihan Apple / Google untuk pembelian dalam aplikasi. Aplikasi ini bukan perangkat medis dan tidak memberikan diagnosis, pengobatan, atau rekomendasi medis. Anda memiliki hak GDPR penuh termasuk akses, penghapusan, dan portabilitas — sebagian besar dapat dilaksanakan langsung di aplikasi.

3. Data yang kami proses

3.1 Data hanya-lokal

Data vaksinasi (profil anggota keluarga, vaksinasi, tanggal, catatan, foto buku/stiker vaksinasi) disimpan hanya secara lokal di perangkat Anda, dalam penyimpanan MMKV terenkripsi (kunci dihasilkan secara acak dan disimpan di Apple Keychain / Android Keystore). Kami tidak pernah mengirim data ini ke server kami atau ke pihak ketiga mana pun.

3.2 Sinkronisasi opsional (iCloud / Google Drive Anda sendiri)

Moje Szczepienia mungkin menawarkan sinkronisasi opsional antara perangkat Anda sendiri menggunakan akun iCloud (iOS) atau Google Drive AppFolder (Android) milik Anda sendiri. Data Anda tetap berada di akun Apple / Google Anda — tidak pernah mencapai server kami. Aplikasi menyimpan data di area AppFolder khusus, yang bersifat pribadi untuk aplikasi dan hanya dapat diakses oleh Anda. Anda dapat menonaktifkan sinkronisasi kapan saja di Pengaturan; menonaktifkan sinkronisasi menghentikan unggahan lebih lanjut tetapi tidak menghapus konten yang sudah ada di iCloud / Google Drive Anda.

3.3 Data diagnostik (Sentry)

Moje Szczepienia mengintegrasikan Sentry (sentry.io) untuk pelaporan kerusakan dan kesalahan. Sentry mengumpulkan:

  • pelacakan tumpukan kesalahan (log kerusakan),
  • info perangkat (model, versi OS, lokal),
  • versi aplikasi dan nomor build.

Sentry tidak mengumpulkan konten Anda (entri, file, catatan vaksinasi, foto, arsip), nama pengguna, atau PII lainnya. Data diagnostik disimpan oleh Sentry hingga 90 hari.

3.4 Periklanan (AdMob)

Moje Szczepienia menampilkan iklan non-invasif hanya di Pengaturan (tidak ada iklan di layar data vaksinasi). Iklan disampaikan oleh Google AdMob, yang SDK-nya mengumpulkan:

  • ID Iklan (Android Advertising ID / Apple IDFA), dibagikan kepada Google untuk menayangkan iklan;
  • data diagnostik (model perangkat, lokasi tingkat negara, bahasa).

Mode default adalah iklan non-personalisasi. Di iOS, perintah App Tracking Transparency (ATT) meminta persetujuan Anda sebelum pengidentifikasi tingkat pelacakan digunakan; di Android Anda mengontrol ID Iklan di bawah Pengaturan sistem. Iklan dapat dinonaktifkan secara permanen melalui IAP Seumur Hidup / Premium.

3.5 Pembelian dalam aplikasi (IAP)

Moje Szczepienia menawarkan fitur berbayar melalui Apple In-App Purchase (iOS) dan Google Play Billing (Android). Saat Anda melakukan pembelian:

  • Apple / Google memproses semua data kartu dan akun — kami tidak pernah melihat nomor kartu, alamat penagihan, atau informasi akun lengkap Anda;
  • Apple / Google mengembalikan token pembelian / tanda terima transaksi yang disimpan Moje Szczepienia secara lokal untuk memvalidasi hak;
  • pembelian pemulihan mengambil ulang hak Anda yang sudah ada dari Apple / Google.

Produk yang tersedia: pembukaan premium seumur hidup, kotak tip opsional, langganan tahunan opsional.

3.6 Izin perangkat

  • Foto / Media (READ_MEDIA_IMAGES / PHPhotoLibrary): menambah atau memproses gambar dari galeri (opsional kecuali diperlukan untuk fungsi inti aplikasi).
  • File (READ_EXTERNAL_STORAGE / iOS Files): memilih dokumen/arsip (hanya saat Anda memilih file).
  • Notifikasi (POST_NOTIFICATIONS / UNUserNotificationCenter): pengingat dan status operasi (opsional).
  • Getar (VIBRATE): umpan balik UI haptic (opsional).

Setiap izin diminta secara kontekstual. Anda dapat menolak izin apa pun dan tetap menggunakan fitur inti (jika berlaku).

3.7 Apa yang TIDAK kami kumpulkan

  • Nama, email, nomor telepon, alamat Anda (tidak diperlukan akun).
  • Daftar kontak, kalender, SMS, log panggilan.
  • Lokasi tepat.
  • Riwayat penjelajahan di luar aplikasi.
  • Data biometrik (Face ID / Touch ID hanya digunakan sebagai kunci tingkat sistem dan tidak pernah meninggalkan perangkat Anda).
  • Data kesehatan (HealthKit / Health Connect), keuangan, atau kartu pembayaran — Moje Szczepienia tidak mengintegrasikan HealthKit atau Health Connect; entri vaksinasi adalah data organisasional yang diketik pengguna, bukan data yang dipertukarkan dengan penyimpanan kesehatan sistem.

4. Mengapa kami memproses data ini (tujuan)

  • Menjalankan aplikasi di perangkat Anda — penyimpanan lokal dan (jika ada) enkripsi memungkinkan data Anda bertahan di antara sesi.
  • Menyinkronkan data Anda sendiri di seluruh perangkat Anda sendiri — melalui iCloud / Google Drive AppFolder Anda sendiri; kami tidak melihat data ini.
  • Meningkatkan stabilitas — diagnostik Sentry membantu memperbaiki kerusakan yang memengaruhi penggunaan Anda.
  • Mempertahankan tingkat gratis — AdMob memberikan iklan non-invasif untuk mendanai pengguna yang tidak membeli premium.
  • Memproses pembelian — penagihan Apple / Google memenuhi hak premium yang Anda pilih untuk dibeli.

5. Dasar hukum (GDPR Article 6)

Untuk pengguna di Wilayah Ekonomi Eropa, Inggris Raya, dan Swiss:

  • Pelaksanaan kontrak (GDPR Art. 6(1)(b)) — menjalankan aplikasi, memproses pembelian Anda.
  • Kepentingan sah (GDPR Art. 6(1)(f)) — diagnostik Sentry, pencegahan penipuan / penyalahgunaan, periklanan non-personalisasi. Kepentingan kami adalah meningkatkan stabilitas dan mempertahankan tingkat gratis; ini tidak mengesampingkan hak dasar Anda.
  • Persetujuan (GDPR Art. 6(1)(a)) — periklanan personalisasi, di mana Anda memberikan persetujuan melalui perintah ATT (iOS) atau preferensi dalam aplikasi. Anda dapat menarik persetujuan kapan saja tanpa memengaruhi pemrosesan sebelumnya.
  • Kewajiban hukum (GDPR Art. 6(1)(c)) — hanya ketika kami harus menanggapi permintaan yang sah dari pihak berwenang.

7. Transfer internasional

Beberapa penerima di atas berlokasi di luar Wilayah Ekonomi Eropa (terutama di Amerika Serikat). Apabila transfer terjadi, transfer tersebut dilindungi oleh:

  • keputusan kecukupan Komisi Eropa (EU-US Data Privacy Framework) untuk penyedia yang disertifikasi di bawah Framework, termasuk Google LLC;
  • Klausul Kontrak Standar (SCC) sebagaimana diadopsi oleh Komisi Eropa, dilengkapi dengan perlindungan tambahan jika berlaku;
  • mekanisme transfer yang diterbitkan sendiri oleh penerima (misalnya komitmen privasi korporat Apple yang mengikat).

Anda dapat meminta salinan perlindungan yang relevan dengan menulis ke mail@macsiem.dev.

9. Hak-hak Anda (GDPR Art. 15–22)

Anda memiliki hak-hak berikut terkait data pribadi Anda:

  • Hak akses (GDPR Art. 15) — konfirmasi apakah kami memproses data Anda dan salinannya. Sebagian besar data Anda sudah ada di perangkat Anda; ekspor dari aplikasi atau tulis kepada kami untuk sisanya.
  • Hak untuk perbaikan (GDPR Art. 16) — koreksi data yang tidak akurat. Edit data langsung di aplikasi.
  • Hak untuk penghapusan / "hak untuk dilupakan" (GDPR Art. 17) — hapus semua data melalui Pengaturan → "Hapus semua data", atau dengan menghapus instalasi aplikasi.
  • Hak untuk membatasi pemrosesan (GDPR Art. 18) — meminta penghentian sementara; tulis kepada kami.
  • Hak atas portabilitas data (GDPR Art. 20) — Pengaturan → "Ekspor data" menghasilkan bundel JSON / Markdown.
  • Hak untuk keberatan (GDPR Art. 21) — keberatan terhadap pemrosesan berdasarkan kepentingan sah, terutama iklan gaya profil. Nonaktifkan iklan personalisasi di pengaturan aplikasi atau melalui kontrol sistem.
  • Hak untuk tidak menjadi subjek keputusan otomatis (GDPR Art. 22) — Moje Szczepienia tidak membuat keputusan otomatis dengan efek hukum atau serupa yang signifikan tentang Anda.

Untuk melaksanakan hak apa pun, tulis ke mail@macsiem.dev. Kami menanggapi dalam waktu 30 hari (dapat diperpanjang 60 hari untuk permintaan kompleks, dengan pemberitahuan).

10. Hak untuk mengajukan keluhan (GDPR Art. 77)

Jika Anda yakin kami memproses data Anda secara tidak sah, Anda dapat mengajukan keluhan kepada otoritas pengawas. Untuk penduduk Polandia:

Prezes Urzędu Ochrony Danych Osobowych (PUODO) ul. Stawki 2, 00-193 Warszawa, Poland https://uodo.gov.pl

Anda juga dapat mengajukan keluhan kepada otoritas pengawas di tempat tinggal biasa Anda, tempat kerja, atau tempat dugaan pelanggaran di negara EEA lain.

11. Privasi anak-anak

Moje Szczepienia tidak ditujukan untuk anak-anak di bawah 13 tahun (di bawah 16 tahun jika berlaku menurut hukum setempat). Kami tidak secara sengaja mengumpulkan data pribadi dari anak-anak di bawah usia tersebut. Apabila orang tua memasukkan data vaksinasi anak ke dalam aplikasi, aplikasi bertindak sebagai pengatur pribadi bagi orang tua; entri tetap ada di perangkat orang tua di bawah kendali orang tua. Jika Anda yakin seorang anak telah memberikan data pribadi kepada kami tanpa persetujuan orang tua, hubungi kami di mail@macsiem.dev dan kami akan segera menghapusnya.

Tanda "Designed for Families" / "Ages 5+" Apple / Google tidak diatur pada Moje Szczepienia — aplikasi ini diberi peringkat untuk audiens umum 13+.

12. Keamanan

  • Penyimpanan lokal terenkripsi saat istirahat — entri vaksinasi, profil, dan pengingat disimpan dalam MMKV dengan kunci enkripsi turunan perangkat yang disimpan di Apple Keychain (iOS) / Android Keystore (Android). Kunci tidak pernah meninggalkan perangkat Anda.
  • Tidak ada transmisi jaringan data medis — entri vaksinasi tidak pernah dikirim melalui jaringan ke server kami. Satu-satunya titik sentuh cloud opsional adalah iCloud / Google Drive AppFolder Anda sendiri, yang hanya dapat Anda akses.
  • Tidak ada integrasi HealthKit / Health Connect — kami tidak membaca atau menulis ke penyimpanan kesehatan sistem; entri vaksinasi hanyalah data organisasional yang diketik pengguna.
  • Keamanan transportasi — semua panggilan jaringan (pembaruan data referensi vaksin jarak jauh, iklan, IAP) menggunakan HTTPS / TLS 1.2+.
  • Minimalisasi — kami hanya mengumpulkan apa yang diperlukan untuk tujuan organisasi yang tercantum.

Tidak ada sistem yang 100% aman; harap perbarui perangkat Anda dan gunakan kunci perangkat yang kuat.

13. App Tracking Transparency (iOS) dan ID Iklan

Di iOS, sebelum pengidentifikasi tingkat pelacakan digunakan oleh AdMob, Moje Szczepienia menampilkan perintah sistem App Tracking Transparency. Jika Anda menolak, Moje Szczepienia hanya menayangkan iklan non-personalisasi.

Di Android, Anda dapat mengatur ulang atau membatasi ID Iklan Anda di bawah Pengaturan → Google → Iklan. Memilih "Hapus ID iklan" menghentikan AdMob menggunakan pengidentifikasi pribadi; iklan non-personalisasi terus ditampilkan.

14. Pembelian dalam aplikasi

Moje Szczepienia menawarkan produk dalam aplikasi berikut melalui Apple App Store dan Google Play: pembukaan premium seumur hidup, kotak tip opsional, langganan tahunan opsional.

Semua data pembayaran ditangani oleh Apple Inc. (akun App Store / iTunes) atau Google LLC (Play Billing). Kami tidak pernah melihat nomor kartu Anda, alamat penagihan Anda, atau akun Apple ID / Google lengkap Anda. Apple dan Google hanya mengembalikan token pembelian dan metadata hak yang tidak jelas yang kami gunakan untuk membuka fitur. Langganan dapat dibatalkan kapan saja di Pengaturan iOS → Apple ID → Langganan atau di aplikasi Google Play → Langganan; aturan pembatalan diatur oleh Apple / Google.

15. Perubahan pada kebijakan ini

Kami dapat memperbarui kebijakan ini seiring perubahan pada aplikasi, SDK pihak ketiga, atau hukum yang berlaku. Perubahan material akan diumumkan dalam aplikasi dan tanggal "Terakhir diperbarui" di bagian atas akan berubah. Terus menggunakan Moje Szczepienia setelah perubahan merupakan penerimaan kebijakan yang diperbarui.
