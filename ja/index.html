プライバシーポリシー — Moje Szczepienia

最終更新日: 2026-09-16 · 施行日: 2026-05-06

1. 当社について

Moje Szczepienia は、家族向けのモバイル予防接種管理アプリです。家族の予防接種のカレンダー、履歴、リマインダーを提供します。このアプリは情報提供と組織化のみを目的としており、病気の診断、治療、予防を行ったり、医療相談に代わるものではありません。すべての予防接種エントリーは、暗号化されたストレージにてお客様のデバイスにローカルに保存されます。読み取り可能な医療データが当社のサーバーに送信されることは決してありません。当社のサーバーを通過するデータはセクション3.2に記載されています。これには、オプションのサインイン情報、当社には復号できないエンドツーエンドで暗号化された同期データ、および通知を配信するために必要な技術データが含まれます。

データ管理者: Maciej Siemiński — Moje Szczepieniaの開発者 連絡先: mail@macsiem.dev

Google Play経由で配信されるアプリのバージョンについては、データ管理者はLICENCEPRO POLSKA Sp. z o.o., ul. Huculska 6, 00-730 Warszawa, Polskaです。

このプライバシーポリシーは、Moje Szczepieniaがどのような個人データを、どのように、なぜ処理するのか、そしてお客様がどのような権利を持つのかを説明します。

2. 概要（平易な言葉で）

Moje Szczepieniaは個人用予防接種管理アプリであり、予防接種記録は暗号化されたローカルストレージによりお客様のデバイスに保存されます。当社は、読み取り可能な医療データを保存するサーバーを運用していません。当社はUnity Ads（設定画面のみで使用し、健康データ画面では決して使用しません）、クラッシュ報告のためにSentry、お客様ご自身のGoogle Driveへのオプションのバックアップ、お客様のデバイス間のオプションのエンドツーエンド暗号化同期、およびアプリ内購入のためにApple / Googleの課金サービスを利用しています。このアプリは医療機器ではなく、診断、治療、または医療上の推奨を提供することはありません。お客様はアクセス、削除、データポータビリティを含む完全なGDPRの権利を有し、そのほとんどはアプリ内で直接行使できます。

3. 処理するデータ

3.1 ローカルのみのデータ

予防接種データ（家族メンバーのプロフィール、予防接種、日付、メモ、予防接種手帳/シールの写真）は、暗号化されたMMKVストレージ（鍵はランダムに生成され、Apple Keychain / Android Keystoreに保持されます）にてお客様のデバイスにローカルに保存されます。当社がこのデータを読み取り可能な形式で当社のサーバーまたは第三者に送信することは決してありません。このデータはお客様がセクション3.2に記載されているオプション機能のいずれかをオンにした場合にのみ、お客様のデバイスから離れます。

3.2 オプションのアカウント、お客様ご自身のGoogle Driveへのバックアップ、デバイス間の同期、および通知

アカウントへのサインイン。 AppleまたはGoogleでサインインできます。当社のアカウントサービス（Cloudflareがホスト）は、内部ユーザーID、お客様のApple / Googleアカウントの識別子、およびプロバイダーが共有する場合はお客様のメールアドレスを保存します。これに予防接種データは保存されません。アプリ内でアカウントを削除すると、この情報は削除されます。

お客様ご自身のGoogle Driveへのバックアップ。 Googleアカウントを連携すると、アプリは予防接種手帳の写真を含むお客様のデータの暗号化されたバックアップを、お客様のGoogle Drive上のプライベートなアプリフォルダに保持します。このフォルダは非表示であり、本アプリのみがアクセスでき、本アプリがお客様の他のDriveファイルを見ることはできません。暗号化キーは同じプライベートフォルダに保持されるため、新しいスマートフォンではGoogleでサインインするだけでデータを復元でき、リカバリーワードは不要です。これは同時に、ストレージプロバイダーであるGoogleが、Googleアカウント内の他のデータと同様に、技術的にバックアップにアクセスできることを意味します。お客様のデータのコピーが当社のサーバーに保存されることはありません。 設定でバックアップをオフにすることができ、それにより以降のアップロードは停止します。バックアップ自体を削除するには、Google Drive内のアプリの非表示データ（設定 → アプリの管理）を削除してください。

デバイス間の同期。 デバイスをペアリングすると、エントリーは当社の中継サーバー（Cloudflareがホスト）を介してエンドツーエンドで暗号化されてデバイス間を移動します。中継サーバーは、お客様がペアリングを解除するまで、または最後のアクティビティから最大365日間、ペアリングされたデバイスのプッシュ通知トークンとともに、復号できない暗号化されたデータのみを保存します。新しいエントリーに関する通知はExpoプッシュサービスを介して配信され、これに予防接種データは含まれません。

お知らせと通知。 アプリ内のお知らせを表示し、通知を送信するために、アプリはランダムなインストール識別子、プッシュ通知トークン、プラットフォーム、言語、アプリのバージョン、リリースチャンネル、およびPremiumが有効かどうかを当社の通知サービス（Cloudflareがホスト）に登録します。これに予防接種データは含まれず、お客様が削除をリクエストするまで保持されます。

暗号化ファイル。 暗号化されたバックアップファイルをエクスポートして、iCloud Drive、Google Drive、ファイルアプリなど、任意の場所に保存することもできます。

3.3 診断データ（Sentry）

Moje Szczepieniaは、クラッシュおよびエラー報告のためにSentry（sentry.io）を統合しています。Sentryは以下を収集します。

  • エラースタックトレース（クラッシュログ）
  • デバイス情報（モデル、OSバージョン、ロケール）
  • アプリのバージョンとビルド番号

Sentryは、お客様のコンテンツ（エントリー、ファイル、予防接種記録、写真、アーカイブ）、ユーザー名、またはその他のPIIを収集しません。診断データはSentryによって最大90日間保持されます。

3.4 広告（Unity Ads）

Moje Szczepieniaは、設定画面のみで非侵入型の広告を表示します（予防接種データ画面では広告は表示されません）。広告はUnity Adsによって配信され、そのSDKは以下を収集します。

  • Advertising ID（Android Advertising ID / Apple IDFA）。広告配信のためにGoogleと共有されます。
  • 診断データ（デバイスモデル、国レベルの位置情報、言語）。

デフォルトモードはパーソナライズされていない広告です。iOSでは、App Tracking Transparency（ATT）プロンプトが、トラッキングレベルの識別子が使用される前にお客様の同意を求めます。Androidでは、システム設定でAdvertising IDを管理できます。広告は、Lifetime / Premium IAPを通じて永続的に無効にできます。

3.5 アプリ内購入（IAP）

Moje Szczepieniaは、Apple In-App Purchase（iOS）およびGoogle Play Billing（Android）を通じて有料機能を提供しています。購入を行う際:

  • Apple / Googleがすべてのカードおよびアカウントデータを処理します — 当社はカード番号、請求先住所、または完全なアカウント情報を閲覧することはありません。
  • Apple / Googleは、Moje Szczepieniaが資格を検証するためにローカルに保存する購入トークン/取引レシートを返します。
  • 購入を復元すると、Apple / Googleから既存の資格が再取得されます。

利用可能な製品: 永久プレミアム解除、オプションのチップジャー、オプションの年間サブスクリプション。

3.6 デバイス権限

  • 写真 / メディア (READ_MEDIA_IMAGES / PHPhotoLibrary): ギャラリーから画像を追加または処理する（アプリのコア機能に必要な場合を除きオプション）。
  • ファイル (READ_EXTERNAL_STORAGE / iOS Files): ドキュメント/アーカイブを選択する（ファイルを​​選択した場合のみ）。
  • 通知 (POST_NOTIFICATIONS / UNUserNotificationCenter): リマインダーと操作ステータス（オプション）。
  • バイブレーション (VIBRATE): 触覚UIフィードバック（オプション）。

各権限は状況に応じて要求されます。いずれかの権限を拒否しても、コア機能（該当する場合）を引き続き使用できます。

3.7 収集しないデータ

  • お客様の氏名、電話番号、または住所。アカウントは必須ではなく、お客様のメールアドレスはお客様がサインインを選択した場合にのみ処理されます（セクション3.2）。
  • 連絡先リスト、カレンダー、SMS、通話履歴。
  • 正確な位置情報。
  • アプリ外の閲覧履歴。
  • 生体認証データ（Face ID / Touch IDはシステムレベルのロックとしてのみ使用され、デバイスから出ることはありません）。
  • 健康（HealthKit / Health Connect）、財務、または支払いカードデータ — Moje SzczepieniaはHealthKitまたはHealth Connectとは統合していません。予防接種のエントリーはユーザーが入力した組織化データであり、システムヘルスストアと交換されるデータではありません。

4. このデータを処理する理由（目的）

  • お客様のデバイスでアプリを実行するため — ローカルストレージと（存在する場合）暗号化により、セッション間でデータが保持されます。
  • お客様ご自身のデータのバックアップと同期 — お客様ご自身のGoogle Driveへのバックアップおよびお客様ご自身のデバイス間のエンドツーエンド暗号化同期。当社はこのデータを読み取ることができません。
  • 安定性を向上させるため — Sentry診断は、お客様の利用に影響を与えるクラッシュを修正するのに役立ちます。
  • 無料版を維持するため — Unity Adsは、プレミアムを購入しないユーザーに資金を提供するために非侵入型広告を配信します。
  • 購入を処理するため — Apple / Googleの請求により、お客様が購入を選択したプレミアム資格が満たされます。

5. 法的根拠（GDPR Art. 6）

欧州経済領域、英国、スイスのユーザー向け:

  • 契約の履行（GDPR Art. 6(1)(b)） — アプリの実行、オプションのアカウント、バックアップとデバイス間の同期、通知、お客様の購入の処理。
  • 正当な利益（GDPR Art. 6(1)(f)） — Sentry診断、詐欺/悪用防止、非パーソナライズド広告。当社の利益は安定性の向上と無料版の維持であり、お客様の基本的な権利を侵害するものではありません。
  • 同意（GDPR Art. 6(1)(a)） — パーソナライズド広告で、ATTプロンプト（iOS）またはアプリ内設定を通じて同意を付与した場合。お客様はいつでも同意を撤回できますが、それ以前の処理には影響しません。
  • 法的義務（GDPR Art. 6(1)(c)） — 当局からの合法的な要求に応じなければならない場合のみ。

9. お客様の権利（GDPR Art. 15–22）

お客様は、ご自身の個人データに関して以下の権利を有します。

  • アクセス権（GDPR Art. 15） — 当社がお客様のデータを処理しているかどうかの確認と、そのコピー。ほとんどのデータはすでにデバイス上にあります。アプリからエクスポートするか、残りのデータについては当社にご連絡ください。
  • 訂正権（GDPR Art. 16） — 不正確なデータを訂正します。アプリ内でデータを直接編集してください。
  • 消去権 / 「忘れられる権利」（GDPR Art. 17） — 設定 → 「すべてのデータを消去」からすべてのデータを削除するか、アプリをアンインストールしてください。アプリ内でアカウントを削除してください。Google Driveからバックアップを削除してください（設定 → アプリの管理）。通知の登録については、当社にご連絡ください。
  • 処理制限権（GDPR Art. 18） — 一時的な停止を要求できます。当社にご連絡ください。
  • データポータビリティ権（GDPR Art. 20） — 設定 → 「データのエクスポート」でJSON / Markdownバンドルが生成されます。
  • 異議を唱える権利（GDPR Art. 21） — 正当な利益に基づく処理、特にプロファイリング型の広告に異議を唱えることができます。アプリ設定またはシステムコントロールでパーソナライズされた広告を無効にしてください。
  • 自動化された決定の対象とならない権利（GDPR Art. 22） — Moje Szczepieniaは、お客様に関して法的または同様に重大な影響を伴う自動化された決定を行うことはありません。

いずれかの権利を行使するには、mail@macsiem.devまで書面でご連絡ください。当社は30日以内に応答します（複雑な要求の場合は、通知により60日間延長されることがあります）。

11. 子供のプライバシー

Moje Szczepieniaは13歳未満の子供を対象としていません（現地法により16歳未満の場合も含む）。当社はその年齢未満の子供から意図的に個人データを収集することはありません。親が子供の予防接種データをアプリに入力する場合、アプリは親のための個人オーガナイザーとして機能します。エントリーは親のデバイス上に親の管理下に残ります。お子様が親の同意なしに個人データを提供したと思われる場合は、mail@macsiem.devまでご連絡ください。速やかに削除いたします。

「Designed for Families」/「5歳以上」のApple / GoogleのフラグはMoje Szczepieniaでは設定されていません — このアプリは13歳以上の一般向けと評価されています。

12. セキュリティ

  • 静止時暗号化されたローカルストレージ — 予防接種のエントリー、プロフィール、リマインダーは、Apple Keychain（iOS）/ Android Keystore（Android）に保持されるデバイス由来の暗号化キーを使用してMMKVに保存されます。キーはデバイスから出ることはありません。
  • 当社はお客様の予防接種データを読み取ることはできません — エントリーはお客様がバックアップまたはデバイス間の同期をオンにした場合にのみデバイスから離れます。バックアップはお客様ご自身のGoogle Driveに保存され、当社のサーバーに送信されることは決してありません。同期データは、当社が復号できないエンドツーエンドで暗号化されたデータとしてのみ、当社の中継サーバーを通過します。
  • HealthKit / Health Connectとの統合なし — 当社はシステムヘルスストアから読み書きしません。予防接種のエントリーはユーザーが入力した組織化データのみです。
  • 転送セキュリティ — すべてのネットワーク呼び出し（リモートワクチン参照データ更新、広告、IAP）はHTTPS / TLS 1.2+を使用します。
  • 最小化 — 当社は、記載された組織目的のために必要なもののみを収集します。

100%安全なシステムはありません。デバイスを最新の状態に保ち、強力なデバイスロックを使用してください。

13. App Tracking Transparency（iOS）とAdvertising ID

iOSでは、Unity Adsによってトラッキングレベルの識別子が使用される前に、Moje SzczepieniaはシステムApp Tracking Transparencyプロンプトを表示します。お客様が拒否した場合、Moje Szczepieniaは非パーソナライズド広告のみを配信します。

Androidでは、設定 → Google → 広告でAdvertising IDをリセットまたは制限できます。「広告IDを削除」を選択すると、Unity Adsが個人識別子を使用することを停止しますが、非パーソナライズド広告は引き続き表示されます。

すべての支払いデータはApple Inc.（App Store / iTunesアカウント）またはGoogle LLC（Play Billing）によって処理されます。当社はカード番号、請求先住所、またはお客様の完全なApple ID / Googleアカウントを閲覧することはありません。AppleとGoogleは、機能のロックを解除するために使用する不透明な購入トークンと資格メタデータのみを返します。サブスクリプションは、iOSの設定 → Apple ID → サブスクリプション、またはGoogle Playアプリ → サブスクリプションでいつでもキャンセルできます。キャンセルルールはApple / Googleによって管理されます。
